# LLM Inference Gateway

A lightweight API gateway for LLM inference built with Python and FastAPI.

## Current Features

- FastAPI application setup
- Health-check endpoint
- Centralized application configuration
- Modular project structure

## Tech Stack

- Python
- FastAPI
- Uvicorn
- Pydantic Settings
